# San dwichaso

Página para encargar un sándwich personalizado: elegís el sándwich, se despliegan el pan y los agregados (a la derecha el sándwich se va armando con una animación en SVG a medida que elegís), y se genera el pedido y se manda por WhatsApp a San dwichaso.

Abrí `index.html` en el navegador o publicala con GitHub Pages.
